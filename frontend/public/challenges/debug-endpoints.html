🎓 Security Notes

Debug-mode endpoints were left enabled when this application was deployed to production. They dump process.env including all secrets and internal state. No authentication is required to call them.

Click any of the endpoint buttons. No authentication, no authorization — anyone can call them. The /api/debug/env endpoint is particularly interesting because it dumps all environment variables including secrets.

Fix

  • Completely remove debug endpoints from production builds — not just hide them
  • Use build-time flags (NODE_ENV=production) to exclude debug routes entirely
  • If debug endpoints must exist, gate them behind strong admin auth and IP allowlisting
  • Scan for exposed debug routes as part of your deployment pipeline
  • Monitor access logs for requests to /debug/, /actuator/, etc.
